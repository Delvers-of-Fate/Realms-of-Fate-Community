Classes, movement and currencies

Class selection and mana

Use the Class Tome to choose Mage or Fighter once per run. It applies the class stats and starter items. Mage starts with 8 health and 24 mana, regenerating 1 mana/second; Fighter starts with 12 health and 12 mana, regenerating 0.5/second. These values are editable in data/rof-classes.json.

Download the current class definitions. The old per-item cost fields in that file are legacy compatibility fields; spell JSON supplies the actual costs.

Mana and class state save with the player. The blue mana meter is above health. The retired three-ability Arcanist experiment is not the current control scheme; retained old-save fields do not reactivate it.

Movement

Hold Left Shift while moving forward to sprint (1.65×). Hold Left Ctrl to crouch (0.45×). Standing checks for overhead clearance. These keys are currently fixed; configurable keys, stamina and controller support remain future work.

Define currencies

Save as data/currencies.json. IDs are stable save keys. The atlas/tex fields reference installed sprites for placeholder pickup appearance; no game artwork is distributed by these examples.

Download JSON

{
    "currencies": [
        { "id": "gold", "name": "Gold", "spriteAtlas": "item", "tex": 89 },
        { "id": "guild_tokens", "name": "Guild Tokens", "spriteAtlas": "item", "tex": 88 }
    ]
}

Currency IDs accept lowercase letters, digits, underscore, dot, colon and hyphen, starting with a letter/digit. Multiple mods merge in load order; later currency definitions override matching IDs. Gold stays in the stock balance. Custom balances appear in the Character window and are saved per run, not as account currency.

Place a pickup

In DelvEdit: Place Entity → Realms of Fate Classes → Guild Tokens - 5. Set currencyId and amount. Nearby collection is the default; autoCollect: false requires use/pickup. Alternatively, this object can go in a monster's explicit loot array:

Download JSON

{
  "class": "com.realmsoffate.classes.CurrencyPickup",
  "currencyId": "guild_tokens",
  "amount": 5
}

These presets do not automatically populate existing dungeon loot. Unknown currencies and nonpositive pickup amounts are rejected.

Custom-currency shops

Place Guild Exchange, or configure a CurrencyShop entity/preset in data/entities.dat. Use its trigger or assign it as an NPC use trigger. This is an entity object, not an automatically loaded standalone JSON file.

Download JSON

{
  "class": "com.realmsoffate.classes.CurrencyShop",
  "title": "Guild Exchange",
  "currencyId": "guild_tokens",
  "offers": [
    {
      "cost": 5,
      "stock": 1,
      "item": {
        "class": "com.realmsoffate.classes.ManaWand",
        "name": "Guild Focus",
        "spells": [
          "bolt",
          "heal"
        ]
      }
    }
  ]
}

An offer can override currencyId; otherwise it uses the shop's currency. stock counts purchases available. Purchasing requires a free inventory slot; payment follows validation and item creation. Shops currently sell items, not stat upgrades, and do not buy from players. Stock shops still use gold.

Shared item tooltips

Vanilla and modded inventory items use a shared tooltip layout: name, type, stats, properties, description and relevant focus controls. Focus spell stats include its modifier; the spell list marks the selected slot. Identified stock items retain Delver's own information text. Unidentified effects and descriptions stay hidden.

Comparisons show protection for matching armor slots or base damage for the same weapon type and damage type. Both items must be identified. These are individual stat differences, not overall item scores or DPS.

Edit data/rof-tooltips.json and restart to customize title, stats, mana, accent, muted, positive and negative colors; width, padding and minimumFontScale; or showDescription, showSlots, showControls and showComparison. Set enabled: false to use stock tooltips. Optional descriptions entries map an exact internal item name to identified-only description text. Long panels scale to stay on screen.

This feature uses the mod's shared tooltip adapter and requires no additional JAR patch. The source workspace includes rollback-tooltips.ps1 and a pre-change mod backup. Character-stat hints retain their stock behavior.
