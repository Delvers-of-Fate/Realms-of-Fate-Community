Realms of Fate: Delver mod guide

The current prototype runs inside the installed Delver game using Java Mod Classes. This guide replaces the engine-fork workflow as the main path. You need Delver plus a compatible loader activation step; the mod is not a standalone game.

Prototype status: the inspected Windows build is tested. Mac/Linux, Workshop publication and subscription installation remain unverified. A Workshop subscription alone cannot activate a disabled Java loader.

Start here

  1. Install the mod and enable its loader.
  2. Use the Class Tome to choose Mage or Fighter.
  3. Hold a custom wand, press R to select a spell, and attack to cast.
  4. Edit individual spell JSON files and PNG icons, then restart.

Implemented now

  • Mage/Fighter selection, saved mana and regeneration, blue mana HUD above health.
  • Left Shift sprint and Left Ctrl crouch with a standing-clearance check.
  • Item-bound spell lists, R cycling, up to three visible icon boxes and saved selection.
  • Individual spell JSON files; Heal and wand-projectile behaviors; custom PNG icons.
  • JSON currencies, placeable drops, custom-currency shops and Character-window balances.
  • Editor theme JSON, category colors, collapsible inspector groups and currency dropdowns.
  • Optional startup configuration checks and reversible loader activation.

Not implemented in this mod

Spell/skill trees, point spending, unlock enforcement, homing missiles, summons, controller spell cycling, crafting, quests, achievements and permanent account progression. Prerequisite IDs are currently metadata only. Old engine features do not automatically carry over.

Verification and limits

The current spell build passed 91 compatibility checks, graphical casting/HUD tests, and startup success/failure tests. Existing spell selection survives save/load. These checks do not replace full campaign, death, travel, multi-mod and platform playtesting.

Legacy achievement documentation is retained for reference and clearly marked as engine-only.
