Editor themes and startup checks

Editor companion

Launch DelvEdit with --enable-mod-classes=true. The companion attaches when the editor loads the Class Tome preset; placing a tome is unnecessary. Restart after changing compiled classes or themes.

Inspector headers fold/expand groups. Currency IDs use a dropdown populated from the currency definitions; existing unknown IDs remain selectable. Existing enum, boolean, atlas and file controls retain their stock behavior.

Theme JSON

Edit data/editor-theme.json. Colors accept RRGGBB or RRGGBBAA, optionally prefixed with #. Set enabled to false to retain the stock editor appearance.

text colors text; heading colors headings; panel colors panels; input colors fields; selection colors selected/hovered rows; button colors buttons. Category names are exact; children inherit category colors. Invalid settings log an error and use defaults.

This changes editor controls and colors, not the full engine-fork hierarchy, toolbar or OS dialogs. There is no theme picker/live reload yet. Game HUD colors are separate.

Startup checks

Edit data/rof-startup.json. The optional screen checks classes, currencies, spell definitions/starter wand lists and item presets. It runs after loader activation, not during the game's earlier startup. Its progress counts completed checks, including failures.

Download JSON

{
  "enabled": true,
  "title": "REALMS OF FATE",
  "background": "151B26",
  "text": "E4E9F2",
  "accent": "87B9ED",
  "error": "F29B91",
  "autoCloseSeconds": 1
}

Successful checks close after autoCloseSeconds (0–10). Errors stay visible until Continue anyway or Enter; the log has details. enabled:false bypasses the screen. It does not appear inside DelvEdit. The intro handoff resets its logo animation to avoid duplicate logos.
