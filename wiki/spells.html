Wiki / Delver mod prototype

Spells, icons and wands

Each spell lives in its own JSON file. A wand lists spell IDs, the HUD reads their icons, R changes the selected index, and attack runs the selected effect after checking mana.

Carryable spell scrolls

Four prototype scrolls add one-use options to the existing loot pool. Pick one up, face your target, then use it from inventory. Any class can use them, even at zero mana. Existing stock scrolls and charged wands retain their behavior.

ScrollEffect
Thunderwave4 magic damage and knockback to nearby hostile monsters within 3 units.
Scorching RayThree fire projectiles in a 16-degree spread; 4 damage each.
WebA 5-second slowing field; enemies move at 35% speed, with up to 0.75 seconds of lingering slow.
Cloud of DaggersA 5-second field dealing 2 physical damage every half second.

Web and Cloud of Daggers appear up to 4 units ahead, stopping before solid world geometry. Their radius is 1.4 units. Fields disappear when leaving the level. These are Delver adaptations with prototype effects and balance.

For immediate testing, place the four Scroll of ... presets under Realms of Fate Classes in DelvEdit. Random loot is not guaranteed in every run.

Authors configure these in data/scroll-spells/*.json, separately from wand spells. A com.realmsoffate.classes.TacticalScroll item uses spellId to reference the filename without its extension. Supported types are wave, volley, web and daggers. Damage, projectile count, radius, range, duration in seconds, spread in degrees, speed, force, slow multiplier and color are configurable. Restart after changing definitions.

Simple wand controls

Spells belong to the wand: equip it, press R to switch, and attack to cast. Mana Focus carries Bolt and Heal; Seeker Focus carries Bolt and Seeking Missile. There is no SPELLS tab, slot assignment, spell-learning requirement or modifier picker.

Mod authors set the item's spells array in JSON, normally one to three IDs. Spell definitions, icons, mana costs and projectile behavior remain configurable. Ordinary charged wands retain stock behavior.

Older customizable focuses retain their exact spell lists, selected spell, fixed modifier effects and previous Mage requirement. R skips empty entries; longer saved lists are not truncated. Learned-spell save data remains readable but unused. Legacy spell tomes now direct players to find wands; the customization and learning-tome editor presets are retired.

Define a spell

Save this as data/spells/heal.json inside the mod. The default Heal costs 8 mana and restores up to 3 HP; full health spends no mana.

Download JSON

{
  "id": "heal",
  "name": "Heal",
  "icon": "ui/spells/heal.png",
  "effect": "heal",
  "manaCost": 8,
  "healAmount": 3,
  "requires": []
}

Magic Bolt uses data/spells/magic-bolt.json. Keep the ID bolt for compatibility with existing wands.

Download JSON

{
  "id": "bolt",
  "name": "Magic Bolt",
  "icon": "ui/spells/magic-bolt.png",
  "effect": "projectile",
  "damage": 4,
  "speed": 10,
  "lifetime": 4,
  "color": "80BFFF",
  "manaCost": 4,
  "requires": []
}

Field reference

FieldMeaning
idUnique stable ID; lowercase letters, digits, underscores or hyphens, starting with a letter/digit.
nameNonempty display name, at most 60 characters.
effectheal, projectile, homing_projectile, or legacy wand_projectile.
manaCostPositive integer mana spent per cast.
healAmountPositive integer required for heal; capped by missing HP.
iconOptional PNG path under ui/spells/. Missing/broken images use a fallback and log once.
requiresOptional prerequisite ID array. References are checked; unlocking is not enforced yet.

Connect a wand

This is an item object for a class's startingItems, a shop offer's item, or an item preset in data/entities.dat. It is not a standalone file the game automatically loads.

Download JSON

{
  "class": "com.realmsoffate.classes.ManaWand",
  "name": "Apprentice Focus",
  "spells": [
    "bolt",
    "heal"
  ],
  "selectedSpell": 0,
  "cycleKey": 46
}

selectedSpell is zero-based. cycleKey: 46 is R. Spell lists belong to the item and survive saving; up to three boxes show at once, with the active spell highlighted. Longer lists show the selected group of three.

Create a variation

Save this as data/spells/greater-heal.json, then add greater_heal to a new wand preset's spell list. This reuses Heal behavior without adding Java. Its prerequisite is metadata, not an unlock gate.

Download JSON

{
  "id": "greater_heal",
  "name": "Greater Heal",
  "icon": "ui/spells/heal.png",
  "effect": "heal",
  "manaCost": 12,
  "healAmount": 6,
  "requires": [
    "heal"
  ]
}

Create original transparent PNGs, preferably 16Ã—16 pixels. Put them in ui/spells/, set the JSON icon path, and restart. Nearest-neighbor filtering keeps the pixels crisp. The bundled Bolt and Heal icons are original work. PNG changes do not require compilation.

Per-spell projectiles and Seeking Missile

Bolt now uses a straight projectile; Seeking Missile uses homing_projectile. Each owns its damage, speed, lifetime and color. The wand's damage roll does not override these definitions. The legacy wand_projectile effect still uses the wand's projectile.

Save this as data/spells/seeking-missile.json. Place Seeker Focus under Realms of Fate Classes in DelvEdit for a wand with Bolt, Heal and Seeking Missile. Existing saved wands retain their lists.

Download JSON

{
  "id": "seeking_missile",
  "name": "Seeking Missile",
  "icon": "ui/spells/seeking-missile.png",
  "effect": "homing_projectile",
  "manaCost": 6,
  "damage": 5,
  "speed": 7,
  "lifetime": 5,
  "targetRange": 8,
  "turnRate": 120,
  "color": "CF89FF",
  "requires": []
}

damage is fixed magic damage before target defenses (1–10000). speed is world units/second (0.1–30); lifetime is seconds (0.1–20); color is six-digit RGB without #. Homing uses targetRange in world units (0.1–30) and turnRate in degrees/second (1–720).

The missile acquires a live hostile Monster ahead of it across clear world geometry, retains a valid target, and can reacquire after loss. It flies straight without a target and uses stock wall/entity impacts. This is steering, not obstacle navigation; dynamic obstacles may intercept it. Projectiles expire and are not persisted in saves. Summons, bouncing and piercing still need future work.

Migration and validation

Definition edits affect saved wands after restarting. Preset spell-list edits affect newly created items; saved wands retain their IDs and selection. Old per-wand manaCost, healManaCost and healAmount fields remain readable but JSON now supersedes them. Put custom values in separate definitions and reference their IDs.

Definitions load from enabled mods in sorted filename order within each directory. Duplicate IDs are rejected. Invalid definitions fail the startup spell check and disable casting until corrected and restarted. Skill trees, point spending and permanent unlocks are not implemented.
